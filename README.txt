CALISTHENICS 120 - OFFLINE APP
==============================
Works fully offline once installed. All 120 days from your Excel plan are inside.

A) INSTALL ON PC (Windows, Chrome or Edge) - no hosting needed
 1. Unzip this folder. Install Python from python.org if you do not have it.
 2. Double-click start-pc.bat. Your browser opens http://localhost:8123.
 3. Click the install icon at the right of the address bar (or Menu > Install Calisthenics 120).
 4. After installing you can close the black window. The app starts from the Start menu / desktop
    and works with no internet and no server.

B) INSTALL ON ANDROID PHONE
 Phones need the app on an https address once. Free options, no coding:
 1. Go to app.netlify.com/drop (or Cloudflare Pages / GitHub Pages) and drag the unzipped folder in.
 2. Open the https address it gives you in Chrome on your phone.
 3. Menu (three dots) > Install app (or Add to Home screen) > Install.
 4. Open it from the home screen icon. It now works offline, including in airplane mode.

C) REAL APK (optional)
 After step B, go to pwabuilder.com, paste your https address, choose Android and download the package.

NOTES
 - Accounts and progress are stored on each device. Phone and PC do not sync.
 - Use Settings > Copy backup regularly. Clearing browser data or uninstalling can erase progress.
 - To update the app later, replace the files and bump CACHE in sw.js (calis120-v1 -> v2).
